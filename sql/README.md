# SQL file notes

`SQL_scriptd_lab2.2.sql` is a coursework collection of validation queries and a possible `DimEmployee` date-column adjustment. It is **not** a complete database installation script and should not be run blindly from top to bottom: some statements are intended for the staging database (`AWN_STG_Demo`) and others target the warehouse database (`AWN_DW_Demo`).

The original staging and warehouse creation scripts (`1_AWN_STG_Demo.sql`, `2_AWN_DW_Demo.sql`) were supplied as course materials and are intentionally **not** redistributed here. See the main README for reproduction requirements.
